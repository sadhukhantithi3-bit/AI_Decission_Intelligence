# 🤖 AI Decision Intelligence Platform

An AI-powered data analytics platform built using Streamlit, Python, Machine Learning, and Google Gemini AI.

## 🚀 Features

- 🔐 User Login Authentication
- 📂 CSV File Upload
- 🧹 Automatic Data Cleaning
- 📊 KPI Dashboard
- 📈 Interactive Charts
- 🤖 AI Business Assistant (Gemini AI)
- 📉 Sales Forecasting
- 🚨 Anomaly Detection
- 📄 PDF Report Generation
- 🌙 Dark Theme UI

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Google Gemini API
- ReportLab

## 📦 Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
